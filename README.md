# Klasemen Serasa

Website statis Liga Serasa periode 2024 - 2027.

## Isi folder
- `index.html` : halaman website (jangan ganti namanya)
- `data.js`    : daftar nama, status, dan lama bulan (file inilah yang diedit)
- `foto-grup.jpg` : foto grup di bagian atas (ganti dengan foto lain dengan nama yang sama)

## Cara mengubah data
1. Buka repositori di GitHub, klik file `data.js`.
2. Klik ikon pensil (Edit).
3. Ubah nama, status (`pacaran`, `pdkt`, `jomblo`), atau lama bulan.
4. Klik **Commit changes**. Website ikut berubah dalam 1 sampai 2 menit.
